# Historias de Usuario

| ID | Historia de Usuario |
| :--- | :--- |
| **HU01** | **Como** administrador, **quiero** registrar productores, asociaciones y parcelas georreferenciadas, **para** tener el origen exacto del producto. |
| **HU02** | **Como** recolector, **quiero** registrar la cosecha en campo desde una app móvil (incluso sin internet), **para** generar el pre-lote y sincronizarlo luego. |
| **HU03** | **Como** operario de acopio, **quiero** registrar la recepción y el pesaje oficial, **para** consolidar los pre-lotes en un lote único del sistema. |
| **HU04** | **Como** responsable de calidad, **quiero** ingresar los parámetros de calidad (calibre, descarte) del lote, **para** determinar su clasificación o rechazo. |
| **HU05** | **Como** sistema, **quiero** generar un identificador único y un código QR por lote/pallet, **para** permitir su etiquetado e identificación física. |
| **HU06** | **Como** encargado logístico, **quiero** registrar la guía, vehículo y precinto de seguridad, **para** controlar el despacho y estado del inventario. |
| **HU07** | **Como** público consumidor, **quiero** escanear el código QR, **para** visualizar el origen y recorrido público de la palta. |
| **HU08** | **Como** administrador/comprador, **quiero** visualizar indicadores de mermas y rendimientos, **para** analizar la eficiencia de la cadena logística. |
