## Diferencias que no deben confundirse

- CI aprobado demuestra comprobaciones de un SHA. Un job que levanta Compose y luego termina no despliega automáticamente a un entorno persistente: CD exige evidencia separada.
- Caché instalada, TTL y pruebas fría/caliente demuestran configuración/corrección, no mejor latencia ni capacidad. Se mantiene una lectura de estado/versión en PostgreSQL por consulta; se necesita medición representativa para afirmar un beneficio.
- El objetivo EQ-01 de 100 usuarios virtuales/10 minutos y P95≤2 s era **propuesta por validar**, no requisito adoptado ni medición. El límite actual compartido por IP de 60 solicitudes/minuto puede hacer que un generador k6 de una IP mida 429. Definir primero escenarios permitidos/abuso y un perfil autorizado compatible; no desactivar controles silenciosamente para obtener números verdes.
- Escalabilidad, disponibilidad, offline, reporte, DNS/CDN, informe y presentación requieren su propia evidencia. Arquitectura/documentación/prototipo no son sinónimos de despliegue, servicio productivo o aprobación docente.
